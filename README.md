# Centro-de-Atencion-Tecnologica

Sistema de Gestión de Solicitudes para el Centro de Atención Tecnológica (CAT) de la universidad.  
Este proyecto busca modernizar el proceso de soporte técnico para estudiantes, docentes y administrativos, reemplazando el actual sistema basado en correo electrónico.

## Backlog inicial (Historias de usuario)

1. **Definir modelo de datos para solicitudes**  
   Como analista, quiero definir un modelo de datos adecuado, para asegurar que toda la información relevante de las solicitudes y usuarios se almacene correctamente.

2. **Implementar autenticación de usuarios**  
   Como usuario, quiero iniciar sesión con mi cuenta institucional, para que el sistema valide mi identidad y personalice mi acceso.

3. **Diseñar formulario para nuevas solicitudes**  
   Como usuario, quiero un formulario claro para registrar una solicitud, para que pueda reportar fácilmente mis problemas técnicos al CAT.

4. **Validar datos del formulario de solicitud**  
   Como usuario, quiero que el sistema valide los datos del formulario, para evitar errores y asegurar que mi solicitud sea procesada correctamente.

5. **Listado de solicitudes del usuario registrado**  
   Como usuario, quiero ver una lista de mis solicitudes previas, para consultar el estado de cada una y hacer seguimiento.

6. **Flujo de cambio de estado de la solicitud**  
   Como técnico, quiero poder actualizar el estado de una solicitud, para mantener informados a los usuarios y gestionar mi carga de trabajo.

7. **Asignación de solicitudes a técnicos**  
   Como administrador, quiero asignar solicitudes a técnicos disponibles, para que cada caso sea atendido por la persona adecuada.

8. **Panel para técnicos**  
    Como técnico, quiero un panel con mis solicitudes asignadas, para organizar mi trabajo según prioridades y estados.

9. **Panel para administradores**  
    Como administrador, quiero un panel con métricas y todas las solicitudes, para supervisar el desempeño del equipo y las áreas críticas.

10. **Búsqueda y filtrado de solicitudes**  
    Como usuario, técnico o administrador, quiero buscar y filtrar solicitudes según criterios clave, para encontrar rápidamente la información relevante.

11. **Configurar GitHub Projects con issues, prioridades y estados**  
    Como equipo de desarrollo, quiero gestionar todos los issues en GitHub Projects usando prioridades y estados, para hacer un seguimiento ágil, visual y ordenado de las tareas
